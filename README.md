# Crimson Harvest Fit Check

Paste an EVE Online fit (EFT format) and see whether it is likely to survive the Crimson Harvest event sites (Tetrimon Base and Crimson Gauntlet).

**Use it:** https://bigmos.github.io/crimson-harvest-fit-check/

Or download `crimson-checker.html` and `eve-data.js` into the same folder and open the HTML file. It runs entirely in the browser and needs no internet connection.

## What it does

- Calculates the fit's EHP, resists, local repair, capacitor (including a cap simulation under neuts), paper DPS and fitting from CCP's static data, with all skills at V.
- Compares that against the event NPCs' real damage, damage types, neuts, HP and resists.
- "Correct my fit" tries module and rig swaps, recalculates each one, and keeps those that improve survival and still fit.

## Limits

- Which NPC ships spawn, and how many, follows the EVE University wiki's 2023 write-up of these sites. How many shoot you at once is a slider (60% by default), and it is a guess.
- Rift escalations (Drifters, Rogue Drones, Triglavians) are not included.
- DPS is the paper figure: no tracking, missile application or range.
- Not modelled: Reactive Armor Hardener adaptation, Tech 3 destroyer modes, Triglavian spool-up, fighters, implants, boosters, fleet bursts, overheating.
- Fit stats were checked against Pyfa on a Praxis only. Other hulls are untested against a reference.

## Rebuilding the data

`eve-data.js` is generated by `tools/build_data.py` from the official static data export
(https://developers.eveonline.com/static-data). Put the JSONL zip at `sde-download/sde.zip` and run:

    python tools/build_data.py
